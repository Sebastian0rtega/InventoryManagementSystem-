**requerimientos**
Requerimientos funcionales:

El sistema debe permitir registrar productos, categorías, proveedores y clientes.
El sistema debe gestionar compras y ventas.
El sistema debe mostrar un dashboard con reportes.

Requerimientos no funcionales:

El sistema debe tener autenticación y roles de acceso.
El sistema debe ser desplegable en la nube con CI/CD.

Requerimientos técnicos:
• Git
• Visual Studio Code
• PostgreSQL
• pgAdmin 4
• Draw.io Desktop
• -GitHub Desktop-**opcional**

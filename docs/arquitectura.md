## Arquitectura

- **Frontend:** Aplicación web desarrollada en **Angular + TypeScript**.
- **Backend:** API REST construida en **Node.js + Express + TypeScript**.
- **Base de datos:** **PostgreSQL** con modelo relacional normalizado.
- **Autenticación y roles:** Módulo de seguridad integrado en el backend.
- **Gestión de repositorio:** **GitHub** utilizando **Git Flow** como estrategia de ramas.
- **Infraestructura:** Contenedores con **Docker** y despliegue automático en la nube mediante **CI/CD**.

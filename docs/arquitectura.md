**arquitectura**

Frontend: Aplicación web (angular).

Backend: API REST en node.js.

Base de datos: PostgreSQL con modelo relacional normalizado.

Autenticación y roles: Módulo de seguridad integrado en backend.

Gestión de repositorio: GitHub con Git Flow.

Infraestructura: Docker para contenedores, CI/CD para despliegue automático en la nube.
